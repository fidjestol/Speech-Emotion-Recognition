# API Model Packages

This folder exports nine Speech Emotion Recognition model packages:

- `text_low`, `text_medium`, `text_high`
- `audio_low`, `audio_medium`, `audio_high`
- `audio_text_low`, `audio_text_medium`, `audio_text_high`

Each package is written to `api_models/artifacts/<model_id>/` and contains:

- `model.joblib`: serialized sklearn pipeline
- `manifest.json`: model tier, modality, classes, components, source tables, and summary metrics
- `feature_schema.json`: exact text and numeric feature inputs expected by the model
- `metrics.json`: held-out test metrics and classification report

The global `api_models/artifacts/registry.json` indexes all nine packages.

## Export

```bash
.venv/bin/python api_models/export_api_models.py
```

By default the export includes the project's `xxx` class because the full BERT and audio feature tables include it. To train only named emotion labels:

```bash
.venv/bin/python api_models/export_api_models.py --exclude-xxx
```

## API Input Contract

A prediction payload has this shape:

```json
{
  "text": "I can't believe this happened.",
  "features": {
    "prosody_energy__rms_db_mean": -18.2
  }
}
```

Text-only low tier needs only `text`. Models that include BERT expect BERT feature values generated by the same `bert-base-uncased` mean-pooling setup used in `extracted_features/text/bert_embeddings.csv`.

Audio and audio+text models expect numeric audio feature-family values under `features`. The exact required names are listed in each package's `feature_schema.json`.

## Prediction Helper

```bash
.venv/bin/python api_models/predict.py api_models/artifacts/text_low \
  --payload '{"text":"I am really upset about this."}'
```

For application code:

```python
from pathlib import Path
from api_models.predict import SERModelPackage

model = SERModelPackage(Path("api_models/artifacts/text_low"))
result = model.predict({"text": "I am really upset about this."})
print(result["emotion"])
```
